## Test plan

| Line | Plan |
|---|---|
| Hypothesis | For the weekend-hiker persona, a headline that names a proof point earns more link clicks than one that names the benefit, and a guarantee does too. |
| The one change | The headline only; primary text, media, audience and budget split held still |
| Metric | Click-through rate (link clicks / impressions), because a headline earns the click |
| Smallest change worth detecting | 18% relative (the team's own call) |
| Sample, budget, duration | From `power.py` below: three arms, so alpha is split across two comparisons |
| Stopping rule | Decide once, at the planned sample; no early stop, no extension |
